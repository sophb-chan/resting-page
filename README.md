# resting page

a small site i made to show some useful and fun info while my chromebook is not being used

## repository structure

the page's source code is in the [`/src`](/src/) folder

you can visit the hosted page by [clicking here](https://resting-page.vercel.app/).

## info you'll see

- battery percentage
- battery charging status
- battery charge/discharge duration
- online status
- connection type
- effective connection speed
- ping
- date and time
- fps
- javascript heap usage

& probably more in the future
